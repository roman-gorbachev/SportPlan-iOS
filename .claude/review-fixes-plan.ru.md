# Блок «Правки по ревью» — план

## Контекст
Брат вручную протестировал приложение и прислал список замечаний (A1–A3, B1–B6, C1–C3). Его ветку не мержим: она писалась на Windows без компилятора и разошлась с этапами 6–7. Список берём как задачи и делаем сами отдельным блоком до этапа 8: общие компоненты (строка списка со свайпом, шиты) понадобятся редактору блинов.

На симуляторе подтверждено:
- **A1:** при свайпе в справочнике у карточки прямой угол справа сверху, текст строки пропадает, полного свайпа нет (`allowsFullSwipe: false`).
- **A3:** экран дня сначала показывается с маленьким заголовком, после загрузки заголовок становится большим и контент прыгает. Причина: `navigationTitle`, `navigationSubtitle` и кнопка «Править» стоят внутри `case .success` в `ProgramDayRoute`.

Решения обсуждения (19.11.2026):
- Свайпы системные (`swipeActions`), как в «Будильнике»: в iOS 26 капсула и так растёт от нуля примерно до 2/3 высоты строки. Свой жест не пишем: дизайн-бриф требует нативных swipe actions.
- Полный свайп включён. Внутри капсулы только иконка; текст остаётся как подпись для VoiceOver. Цвет — системная роль `.destructive`.
- Удаление упражнения из дня — без подтверждения. Удаление дня и программы — с подтверждением, полный свайп его открывает.
- Шапка экрана дня как на экране тренировки: подпись «Программа · B» над большим названием в контенте, маленький заголовок в панели появляется только после прокрутки.
- Вне блока: B4 (экран перед стартом) и C1–C3 — отдельные обсуждения; B6 (убрать пустую тренировку) отклонён; свайп-закрытие плашки отдыха из B3 отклонён, «Пропустить» уже есть в панели отдыха.

## 1. Свайпы и скругления (A1, A2, B1)
- **Причина прямого угла.** Найти на симуляторе, почему строка при свайпе и перетаскивании теряет скругление. Подозрение: наш фон строки `listRowBackground(Palette.surface)` в `appListRow()` (`Packages/SportplanKit/Sources/DesignSystem/Components/View+AppGroupedList.swift`). Чинить в этом общем модификаторе, а не на каждом экране. Если без своего фона системное скругление не получить, сначала показать варианты пользователю.
- **Справочник** (`library/ui/LibraryScreen.swift`): `allowsFullSwipe: true`, кнопка `Label(..., systemImage: "archivebox")` с ролью `.destructive`. Подтверждение для упражнения, которое есть в программах, остаётся как сейчас.
- **Упражнения в дне** (`programs/day/ui/ProgramDayScreen.swift`): `swipeActions` с корзиной вне режима правки, вызывают тот же `onDelete` (`RemovePlannedExerciseUseCase`). В режиме правки остаются `onDelete` / `onMove`.
- **Дни в списке программ** (`programs/ui/ProgramsScreen.swift`, `ProgramDayRow`): свайп «Удалить» → подтверждение → `DeleteProgramDayUseCase`. В `ProgramsViewModel` добавить use case (через `AppDIContainer`), состояние ожидающего удаления дня по образцу `ProgramDeletionConfirmation`, тексты — те же, что в форме дня (`programDay.delete.title`, `programDay.delete.message`).
- **Программы** (`ProgramHeaderRow`): свайп «Удалить» → существующий `onDeleteProgram` с подтверждением. Меню «⋯» остаётся.
- **Подходы в тренировке** (`ActiveWorkoutScreen`): уже корзина с `.destructive`; проверить, что выглядит так же.
- **Перетаскивание (A2):** проверить, что после исправления прямых углов нет в режиме «Править» дня и при перетаскивании везде, где есть `onMove`.

## 2. Заголовки (A3, B2)
- **Экран дня** (`ProgramDayRoute`, `ProgramDayScreen`):
  - первая строка списка — шапка: `subtitle` («Test · B») caption/footnote над `title` в `Typography.largeTitle`, как `header` в `ActiveWorkoutScreen`; отступ — токен `Spacing`;
  - `.navigationBarTitleDisplayMode(.inline)`; заголовок в панели пустой, пока шапка видна, и показывается после прокрутки (`onScrollGeometryChange`, порог — `private static let`);
  - `toolbar` с «Править» — снаружи `switch`, неактивна до загрузки; `navigationSubtitle` убрать.
- **Остальные экраны:** проверить, где заголовок или toolbar ставятся только после загрузки. Уже найдено: `PlannedExerciseGoalsRoute` — заголовок брать из `PlannedExerciseGoalsTarget.exerciseName` / `dayTitle` до загрузки. Пройти все `Route` и вкладки, проверить на симуляторе возврат заголовка при прокрутке вверх.

## 3. Шиты и мелочи (B5 и др.)
- **Выбор упражнения** (`programs/day/picker/ui/ExercisePickerRoute.swift`): «Готово» → `.confirmationAction` (справа), «Новое» → `.topBarLeading` (слева). Остальные шиты уже следуют правилу «главное справа».
- **«+ Подход» / «+ Разминка»** (`ActiveWorkoutScreen.addSetButton`): при крупном тексте переносятся по буквам. Воспроизвести на крупном Dynamic Type и чинить раскладку в `ViewThatFits`.
